# 📚 Enseñanzas y costumbres de mi comunidad

Este es un proyecto web interactivo diseñado para preservar y difundir las tradiciones culturales de Cerro de Pasco a través de una experiencia narrativa visual.

## 📖 Sobre el proyecto
El proyecto central es la historieta **"El Eco de la Muliza"**, que narra la conexión profunda entre los habitantes de Cerro de Pasco, el clima extremo de la ciudad y la fuerza emocional de su música tradicional: la Muliza.

* **Objetivo:** Fomentar el orgullo regional y la memoria histórica entre los jóvenes.
* **Inspiración:** Basado en las costumbres reales del Carnaval Cerreño y la identidad minera-andina.

## 🚀 Características
* **Experiencia Narrativa:** Interfaz intuitiva para navegar a través de la historia.
* **Diseño Visual:** Estilo artístico adaptado para resaltar el contraste entre el frío de la puna y la calidez del carnaval.
* **Responsive:** Adaptable para visualización en diferentes dispositivos.

## 🛠️ Tecnologías
* **Frontend:** HTML5, CSS3, JavaScript.
* **Diseño:** Ilustración digital personalizada.
